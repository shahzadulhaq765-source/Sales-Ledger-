# SUH Sales Pro GitHub + APK

Upload all files and folders from this package to the repository root.

Required:
- `.github/workflows/build-apk.yml`
- `android-app/`
- PWA files such as `index.html`, `app.js`, `styles.css`

To build APK:
1. Open Actions.
2. Select `Build SUH Android APK`.
3. Click `Run workflow`.
4. Download `SUH-Sales-Pro-APK` from Artifacts.
5. Extract and install `app-debug.apk`.
