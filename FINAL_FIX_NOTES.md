# SUH Sales Pro v6.1 — Invoice Export & Product List Fix

## Fixed
- Included Product SKU Excel list is now imported once per bundled-list version even when old app data already exists.
- Exact user-supplied `product_import_template 12(1).xlsx` is bundled as `product_import_template.xlsx`.
- Invoice PDF generation on Android no longer depends on the large browser canvas/base64 conversion.
- Invoice PDF is generated natively on Android and saved to `Downloads/SUH Sales Pro`.
- Invoice JPG is generated natively on Android and saved to `Downloads/SUH Sales Pro`.
- WhatsApp/share uses a native Android PDF file and Android share sheet.
- Invoice native output contains SUH logo, subtle logo watermark, supplied blue stamp, supplied blue signature, and Authorized area.
- Excel exports generated by the app now use the Android save bridge instead of unsupported WebView blob download behavior.

## Version
- Android versionCode: 7
- Android versionName: 6.1
